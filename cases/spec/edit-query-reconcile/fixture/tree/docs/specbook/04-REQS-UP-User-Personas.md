#   REQS: User Personas (UP)

##  ROLE: Employee

-   TYPE: Person
-   TERM: [[TERM:Employee]]

Searches free rooms, books them, checks in, and cancels the own bookings, BECAUSE the solution
is built for the self-service booking by the employees.

##  ROLE: Facility Management

-   TYPE: Person
-   TERM: [[TERM:Facility Management]]

Cancels any booking, BECAUSE Facility Management stays in charge of the
rooms even though the employees book them themselves.
