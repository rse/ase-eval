# docs/edit-chain

Four documentation skills on one onboarding guide: `ase-docs-proofread
--auto` (seeded typos), `ase-docs-refine --auto`, `ase-docs-shorten --auto
--words 260` (from about 420 words), and `ase-docs-distill --top 5`.
Checked: the typos are gone, the key facts survived, the final length is at
most 290 words, and a rubric over all four stages.
