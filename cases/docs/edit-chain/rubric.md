# Rubric: Proofread, Refine, Shorten, and Distill an Onboarding Guide

An onboarding guide (about 420 words) with seeded spelling errors
("basicaly", "recieve", "localy", "dont", "tuesday", "this windows") and
wordy prose was proofread, refined, shortened to about 260 words, and
finally distilled into its top 5 key points. Judge the whole session output.
Score each criterion and average them:

1.  **Proofreading**: the seeded errors were found and corrected
    (including capitalization of weekdays and the grammar of "this
    windows").
2.  **Refinement**: the wording got tighter and clearer without changing
    facts, numbers, or technical terms.
3.  **Shortening**: the guide reached the word budget while keeping all
    essential facts (disk encryption first, access requests and the
    two-day AWS approval, the dev setup commands, never commit `.env`, PR
    approval rule, deploy days, on-call shadowing, help channel).
4.  **Distillation**: the top-5 list is importance-ranked, each point has a
    rationale and a verbatim line-cited evidence snippet from the document.
5.  **Faithfulness**: no invented content in any stage.
