# Rubric: Conceptual Proximity of Property-Based Testing

The output maps the conceptual neighborhood of "property-based testing".
Score each criterion and average them:

1.  **Parent**: a sensible parent topic (e.g. software testing /
    automated or generative testing).
2.  **Siblings**: relevant sibling topics on the same level (e.g.
    example-based unit testing, fuzzing, mutation testing, model-based
    testing, formal verification).
3.  **Children**: relevant child topics (e.g. generators/arbitraries,
    shrinking, stateful property testing, tools like QuickCheck,
    Hypothesis, fast-check).
4.  **Accuracy**: no misplaced or invented concepts; the relations are
    correct.
5.  **Form**: clearly separated parent / siblings / children with short
    explanations.
